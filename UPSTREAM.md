# Upstream Provenance

Clean Design began as a history-free source snapshot of
[`nexu-io/open-design`](https://github.com/nexu-io/open-design) at tag
`open-design-v0.16.1`, commit
`276b4d8e970bc143d7ad060181a89a834e3d9caf`.

The original Apache-2.0 license is preserved in `LICENSE`, and attribution is
recorded in `NOTICE`. Clean Design is independently named and operated. No
upstream trademark permission or endorsement is claimed.

The Git remote named `upstream` is read-only by project policy. Clean Design is
frozen to this baseline and does not merge later upstream releases wholesale.
Maintainers may manually select a security, provider-compatibility, or macOS
compatibility patch only after reviewing it for:

- account, cloud, team, billing, promotion, update, or deployment coupling;
- telemetry, analytics, relay, affiliate, or other new network destinations;
- coding-agent MCP/plugin installation or direct downstream invocation;
- installed identity, application-data, IPC, or process-stamp collisions; and
- license, trademark, catalog, or visible-branding impact.

Record accepted upstream patches in the commit message with their upstream
commit SHA and keep the Clean Design behavior specs authoritative.
